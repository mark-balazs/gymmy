Mark sees work only once an independent review scores it 8 or more out of 10. Before an idea, a proposal, a mockup, a refinement, implementation hints, a documentation pass or any other deliverable or recommendation reaches him, a fresh agent that did not do the work scores it against the rules that govern it, and a new reviewer scores it again after each round of fixes until it reaches 8. If something only he can decide holds it below 8, he gets that one question, not the work.
