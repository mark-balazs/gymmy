A generated day has five slots, each exercise 3 sets: 6–12 reps for main lifts, 10–15 for isolation and 30–40 m for the finisher. Push/Pull/Legs and Upper/Lower add a rotation-or-carry finisher every day as a bonus, and a repair pass fills any gap so a generated week always covers its split's patterns.
