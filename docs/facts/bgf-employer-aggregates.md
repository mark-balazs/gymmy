In BGF an employer sees aggregates only, never one person's results, and no setting can change that; it sees who is enrolled (a payroll fact), and a withdrawal shows only as 'no longer enrolled'. Whoever sells to companies sees only commercial data, employer and trainer screens never share a query path, and the account always belongs to the person, not the employer.

Never to be built: an employer or agency view of one person, a shared query path between trainer and employer screens, participant data stored on a trainer's device (see trainer-clients-tab), a report that recomputes when viewed (bgf-min-group), or consent stored as a yes/no flag (programme-consent).
