Docs live in two places: Markdown in the repo for whoever edits the code, and Confluence for product, architecture, operations and decisions. When they disagree with each other, with the code or with the fact register, nobody picks a winner: the owner is asked. Decision log entries are appended, never edited, and old ones are marked superseded.
